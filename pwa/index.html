🛡️ Pre-Write Safety Audit

Before anything is written, vibesODB2 checks the following. If any check fails the write is refused and the reason is shown.

✅
Engine Running Interlock (PID 010C)

Engine Speed = 0 RPM (Ignition ON, Engine OFF).

🛡️
Module Blacklist Enforcement

Critical braking (ABS/ESP 0x03), Airbag (0x15), and Power Steering (0x44) are strictly blocked.

📏
Payload Sizing Verification

Writing exact byte count required by ECU schema specification.

💾
Pre-Write Snapshot

The current coding is saved to this browser's local storage before writing. Local storage can be cleared by the browser: export your backups.

🔎
Post-Write Verification

After the ECU acknowledges the write, the coding is read back and compared. If it differs, the saved baseline is written back once. A rejected write (negative response) changes nothing and is reported as failed.

🧾
Live Baseline Required

Writes are only allowed after the current coding has been read from this vehicle in this session.

⚠️

Before you connect to a vehicle

  • Alpha software. It has not been verified on most listed vehicles. Writing to control units can leave features misconfigured or a module unresponsive.
  • Backups are local. Snapshots live in this browser only. Export them before writing anything.
  • Lighting and other regulated behaviour. Some coding options change exterior lighting or safety-related behaviour and may be unlawful on public roads where you are. You are responsible for checking.
  • Fault memory. Clearing fault codes removes information a mechanic may need and resets emissions readiness monitors.
  • Warranty and insurance may be affected by modifying vehicle configuration.
  • No warranty, no liability. This is free open-source software provided as-is (MIT licence). It is not affiliated with any vehicle manufacturer or diagnostic tool vendor.
